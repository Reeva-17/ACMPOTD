## Approach 
Read the entire question using getline() to handle spaces. Traverse the string backward, skipping non-letter characters until the last letter is found. Convert it to lowercase using tolower() and check whether it is a vowel (a, e, i, o, u, y). If it is a vowel, print YES; otherwise, print NO

## Code
```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    getline(cin, s);

    int i = s.size() - 1;

    while (i >= 0 && !isalpha(s[i])) {
        i--;
    }

    char c = tolower(s[i]);

    if (c == 'a' || c == 'e' || c == 'i' ||
        c == 'o' || c == 'u' || c == 'y') {
        cout << "YES" << endl;
    } else {
        cout << "NO" << endl;
    }

    return 0;
}
```
Complexity:

Time Complexity: O(n)

Space Complexity: O(n)
